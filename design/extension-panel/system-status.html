STATE FAMILY: SYSTEM STATUS (not a verdict, not a data answer) maps to → extension/content.js paintStatus() · extension/background.js:84-89
Why one file for four states. Today all four of these collapse into the same paintStatus() function — one generic sentence, always an amber (riq-watch) left border, whether the situation is "wait a minute" or "we are actually broken." That is the exact failure the brief warns about: a user cannot tell "we don't know" apart from "it's broken," except here it's one level worse — a user can't tell "you need to do something" apart from "something is wrong on our end." Grouping them side by side is the fastest way to see the fix: split by severity, not by copy length. Three of these are self-serve (neutral border, an honest sentence, a CTA that resolves it in one click). One is a genuine error (it gets the product's error colour — the extension-card SKIP red, #f87171, reused deliberately rather than inventing a fifth colour — see DESIGN-REVIEW.md §2). None of the four ever borrow amber: amber means WATCH, a verdict, and nothing else.
