The two reusable components
NumbersCard takes 1–3 stats plus n / period / market — the provenance row is a fixed part of the layout, not a caption, so it survives edits that would otherwise trim it for space. HonestyCard reuses the same chrome, radius and shadow language as extension-panel/insufficient.html — the statement sits in the exact slot a price would occupy, at the same weight, so the honest state never reads as broken.
