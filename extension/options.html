Resale IQ

Works on Vinted in Spain, France, Germany, Italy and Portugal only — vinted.es, .fr, .de, .it, .pt. Open an item on one of those to see the panel.

Not available on vinted.co.uk, vinted.com, or any other Vinted site — the panel won't appear there.

Checking connection…

The extension sends the public listing title to resaleiq.dev to look it up, and — only if the panel fails to load — a failure code with no listing text. It never reads your Vinted account.

Methodology · Privacy

Manual token (only if sign-in fails)
